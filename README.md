# Turno Cero

Juego de combate en arena con pixel art. Gana dos rondas contra Vanta en un depósito ferroviario.

## Ejecutar el proyecto

Importa `project.godot` en Godot 4.0 y pulsa **F5**. En Windows también puedes abrir `Jugar.cmd`. El lanzador busca Godot en `E:\Godot` y permite indicar otra ubicación con la variable de entorno `GODOT_EXE`.

## Controles

| Tecla | Acción |
| --- | --- |
| A / D | Moverse. Pulsa dos veces y mantén la segunda pulsación para correr. |
| W / S | Subir o bajar por escaleras. S también agacha y, durante la carrera, activa el deslizamiento. |
| Espacio | Saltar |
| E / Q | Recoger o lanzar el objeto equipado |
| J | Golpear |
| N + K | Mantener N para apuntar y pulsar K para disparar. Mientras apuntas, W/S ajustan la altura y A/D cambian de lado. Un doble toque de S también apunta a la izquierda. |
| R | Cambiar el cargador. Cada arma tiene uno colocado y uno de reserva. Las balas restantes del cargador retirado se descartan. |
| Esc / M | Pausa o sonido |

El deslizamiento esquiva los golpes cuerpo a cuerpo y tiene un 30 % de probabilidad de esquivar cada bala.
